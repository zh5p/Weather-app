# 🌤️ Modern Weather Dashboard App

A sleek, modern, and interactive weather dashboard web application built with vanilla web technologies. It provides real-time weather details, forecasts, and atmospheric conditions for any city worldwide using the OpenWeatherMap API.

---

## ✨ Features

* **Modern Glassmorphism UI:** Clean and stylish user interface featuring backdrop blurring, smooth transitions, and a gorgeous gradient background.
* **Real-Time Weather Data:** Fetches live weather information seamlessly via **OpenWeatherMap API**.
* **Comprehensive Metrics:** Displays detailed insights including:
  * Current temperature along with daily minimum and highest temperatures.
  * Humidity levels and wind speed.
  * Atmospheric pressure.
  * Dynamic weather condition descriptions matched with animated weather icons.
* **Interactive UX:** Supports both button clicks and pressing the `Enter` key to search smoothly.

---

## 🛠️ Tech Stack

* **HTML5:** Structuring semantic layout and DOM elements.
* **CSS3:** Modern styling, Flexbox/Grid layouts, and CSS glassmorphism effects.
* **JavaScript (ES6+):** Managing application logic, asynchronous operations (`Fetch API`, `Async/Await`), and error handling.
* **FontAwesome:** Providing modern UI icons.
* **OpenWeatherMap API:** Serving as the reliable weather data provider.
